使用说明

  1. 下载 ZIP 包后，先完整解压到本地文件夹。
  2. 进入 Xii_Raw_Graph_Portable 文件夹。
  3. 双击 ai_chat_app.exe 启动程序。
  4. 首次使用时，按包内 USER_SETUP_GUIDE.md 配置 API Key。
