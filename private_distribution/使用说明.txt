# 🚀 Xii_Raw Graph - 快速开始指南

## 欢迎使用！

这是一个专为特定用户准备的 AI 聊天应用。

## 📦 安装步骤

### 1. 解压文件
将下载的 ZIP 包解压到任意文件夹。

### 2. 配置 API 密钥
**重要**: 你需要自己的 OpenAI API 密钥才能使用。

#### 获取 API 密钥
1. 访问 [OpenAI 平台](https://platform.openai.com/)
2. 注册/登录账户
3. 进入 API Keys 页面
4. 创建新的 API Key
5. 复制密钥 (格式如: `sk-...`)

#### 配置应用
创建 `config.txt` 文件在应用目录中：
```
OPENAI_API_KEY=sk-your-api-key-here
```

或者设置环境变量：
```cmd
setx OPENAI_API_KEY "sk-your-api-key-here"
```

### 3. 运行应用
双击 `ai_chat_app.exe` 启动应用。

## 🔄 自动更新功能

应用启动时会自动检查新版本。如果有更新，会弹出提示对话框：

### 更新选项
- **自动下载**: 一键下载更新包到下载文件夹
- **手动下载**: 打开浏览器下载更新包
- **稍后提醒**: 暂时跳过更新

### 安装更新步骤
1. 下载完成后，按照控制台提示操作
2. 关闭当前应用
3. 解压新版本文件
4. 覆盖旧文件
5. 重新启动应用

## ❓ 常见问题

### Q: 提示 "API 密钥无效"
A: 检查你的 API 密钥是否正确配置，确保有足够的余额。

### Q: 无法生成图片
A: 确认你的 OpenAI 账户支持 DALL-E 模型。

### Q: 应用闪退
A: 确保网络连接正常，检查防火墙设置。
